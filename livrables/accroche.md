# Concevoir une application web maintenable intégrant un agent IA

Brancher une IA sur une application web prend dix minutes. Vivre avec ensuite,
c'est une autre histoire : la réponse change à chaque appel, la latence
explose, la facture aussi, le fournisseur met à jour son modèle sans prévenir,
et n'importe quel document indexé peut manipuler votre agent.

Ce cours vous apprend à construire une application qui prend tout cela en
compte dès l'architecture. Vous partez d'une application de notes en Laravel
et vous la faites évoluer sur cinq séances : isoler l'IA derrière un port,
construire un agent avec des outils et de la recherche dans vos documents, le
rendre résilient et mesurable, le tester malgré son non-déterminisme, le
protéger, puis le mettre en production.

Un parti pris : pas de SDK d'IA. Vous écrivez chaque brique vous-même, puis
vous la comparez à ce que font le Laravel AI SDK et Spring AI. À la fin, vous
saurez pourquoi chaque pièce existe, et vous saurez défendre vos choix dans
une fiche d'architecture.

**Pour qui ?** Développeurs PHP à l'aise avec Laravel, niveau première année
de mastère. Aucune connaissance en IA requise.

**Ce que vous saurez faire à la fin :** intégrer un agent IA dans une
application web sans dégrader sa maintenabilité, sa testabilité, sa sécurité
ni sa maîtrise en production, et justifier chaque choix technique.

**Durée :** 15 h, cinq séances de 3 h, à votre rythme · **Pré-requis :** PHP
orienté objet, bases de Laravel, API REST, Git. Un modèle local gratuit suffit
pour tous les TP.
