# 01 : Les bases de l'architecture web, et pourquoi l'IA les bouscule

- Durée apprenant : 3h
- Séquences :
  - S1.1 Architectures web : les bases (45 min) : `cours.md` section 1
  - S1.2 Pourquoi l'IA complique les architectures classiques (45 min) : `cours.md` section 2, `exercices.md` exercice 1
  - S1.3 Installer son environnement : IA en ligne ou IA en local (40 min) : `installation.md` (FYC-29)
  - S1.4 TP : réorganiser un code fourre-tout (50 min) : dépôt de départ (FYC-27)
- Objectifs pédagogiques :
  - Reconnaître les couches d'une application web et la place du cœur métier
  - Isoler une dépendance externe derrière un port et la brancher par un adaptateur
  - Nommer les cinq caractéristiques d'un agent IA et en déduire les conséquences sur l'architecture
- Vidéos prévues : vidéo d'intro S1.1 (où placer l'appel à l'IA), démo Laravel / Spring Boot, démo « un port, deux adaptateurs » (S1.3)
- Exercices : exercice 1 (fiche de réponse, corrigé), QCM de 5 questions

- Issue Linear : FYC-5 (chapitre), FYC-26 (support S1.1 et S1.2)
