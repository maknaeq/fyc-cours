# 03 : Rendre son appli fiable et surveillable

- Durée apprenant : 3h
- Séquences (trame V2, `livrables/scenarisation.md`) :
  - S3.1 Délais, files et idempotence (25 min), nouvelle séquence
  - S3.2 Retry, coupe-circuit, repli (40 min)
  - S3.3 Observer l'agent (35 min)
  - S3.4 TP : instrumentation et panne simulée (80 min)
- Note : la V1 totalisait 2 h 40 ; la trame V2 passe à 3 h pile avec la séquence d'idempotence et une correction en trois vidéos courtes
- Objectifs pédagogiques :
  - Rendre résilient l'appel à l'IA : délais enchaînés, idempotence, retry borné, coupe-circuit, repli à trois niveaux (O4)
  - Instrumenter l'agent : une trace par requête, le coût par requête, le modèle et la version de prompt dans chaque trace (O5)
- Vidéos : correction du TP S3.4 en 3 parties de 5 à 7 min
- Exercices : rejeu d'un appel idempotent (S3.1), diagnostic sur traces (S3.3), QCM du chapitre
- Auteurs : Erwin Gossin (S3.1, S3.3), Timothé Geoffroy (S3.2), Kaan Topkaya (S3.4)
